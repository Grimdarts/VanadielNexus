## Revision 2026-11-04 (Claude, after review)

The first build typed the zone connections from memory, and spot checks against BG-Wiki found errors in most
zones checked (Lower Jeuno, Escha - Zi'Tah/Ru'Aun, Western Adoulin…). Changes:

- **Connections come from BG-Wiki.** `tools/fetch_zone_connections.py` reads every zone page's Connected Zone
  table (plus the Survival Guide and Home Point lists) into `tools/world_map/zone_connections.json`; the seed builds
  walking links, one-way exits, Maws/Confluxes, boats and airships from it. Hand-written edges in
  `RAW_EDGES` only add gate names/key items or reach instances without a wiki table; ones the wiki contradicts
  are dropped (the seed prints each). Every edge carries `source` (`bg-wiki`, `curated`, `unverified`). The one
  unverified link is Jeuno ↔ Adoulin.
- **Edges store both sides' grid positions** (`exit_pos` in the from zone, `entry_pos` in the to zone), so a
  step always shows where the exit is in the zone you're leaving.
- **Consolidated nodes are only kept for true multi-layer instances** (Sortie, Odyssey, Salvage, Dynamis [D],
  Campaign, [U]). Dynamis zones, Avatar Cloisters, Promyvions and Assault areas are separate nodes, because each
  is entered from a different place.
- **Routing:** Home Point / Survival Guide warps relax directly (no virtual hub nodes) with a tie-break that
  prefers warping within the same region; the browser export's router is a port tested against Python with Node.
- **Layout:** zones are swapped between grid cells to keep linked zones adjacent (lines through unrelated boxes
  286 → 70), regions are pushed apart so halos don't overlap, and the canvas size follows the layout.
- **Canvas:** zone names hide below 0.62× zoom (region banners stay readable), "Whole map" fits everything,
  Esc clears the selection, route steps wrap instead of being cut off.
- **Browser export:** wheel zoom, drag pan, Whole map / Reset view, labels hide when zoomed out.

## Problem Statement

FFXI's in-game world map is a static parchment painting where players cannot see which zones connect, which transitions are one-way drops or gated behind key items, or how to travel efficiently between zones. Existing community flowcharts ("Full Zone Map V2" on Reddit/Excalidraw) plot 200+ zones and crossed arrows onto a single flat poster that is visually cluttered, omits modern endgame instances (Sortie, Odyssey, Omen, Dynamis Divergence), and cannot compute a route from where the player is currently standing.

In Jason's words: *"The world map in FFXI is never difficult to understand and see the connections between zones [sic: always difficult to see connections]. Would you be able to create a stylized interactive world map I could use to help navigate the FFXI world?"* and *"Right now I'm looking for a clean stylized map layout that's easy to use. I don't want to fill it with clutter yet."*

## What Makes This Cool

- **Calm, uncluttered Geographic Constellation:** Zones sit in their recognizable Vana'diel geography (San d'Oria North, Jeuno Center, Bastok SW, Windurst SE, Aht Urhgan East, Adoulin West, with outer rings for `[S]` Shadowreign, Abyssea, and Escha) inside subtle regional halos, styled in `DESIGN.md`'s night-sky navy (`#0B1020`), crystal cyan (`#22D3EE`), and gold (`#E0B04A`).
- **Era & Endgame Filter Pills:** One-click top filter pills (`All Eras`, `Core & Zilart`, `CoP`, `ToAU`, `WotG [S]`, `Adoulin`, `Escha & Abyssea`, `Endgame`) dim unrelated regions so alternate dimensions (`[S]` past zones, Abyssea, Escha) never turn the main map into spaghetti.
- **First-class Endgame Destinations:** Modern endgame zones—**Sortie** (`Outer Ra'Kaznar [U1–U3]`), **Odyssey** (`Walk of Echoes [P1]/[P2]`), **Omen** (`Reisenjima Henge`), **Dynamis / Dynamis [D]**, **Limbus** (`Temenos` / `Apollyon`), **Nyzul Isle / Salvage**, and **Vagary / Delve / Incursion**—appear as distinct diamond nodes (`◆`) wired directly to their entry hubs.
- **Live "You Are Here" + Weighted Route Finder:** Reads `zone_name` live from `VanadielNexus.lua`'s existing `STATE_UPDATE` UDP broadcast (via `AppContext.zone_changed`) to highlight your current zone in cyan, and computes the fastest hop-by-hop route to any clicked target zone (weighing Home Points, Survival Guides, Mount-allowed zones, and walking exits).
- **Works in the App AND Standalone in Any Browser:** A single canonical graph (`vanadiel_nexus/resources/world_map_data.json`) renders natively inside a `World Map` tab in Vana'diel Nexus (`QGraphicsView`) AND exports a self-contained single-file interactive HTML/SVG map via `Open in Browser ↗`.
- **Drag-to-Arrange Layout Mode:** Just like `LayoutPage` (`ui/pages/layout.py`), toggling `Arrange Layout: On` lets Jason drag zone nodes or regional halo banners directly on the canvas (live-updating connected lines and region bounding halos) and save updated `(x, y)` coordinates so both the desktop tab and standalone HTML map stay visually balanced with zero overlapping labels.

The in-app map must use `PySide6.QtWidgets` (`QGraphicsScene`, `QGraphicsView`) and `PySide6.QtGui` (`QPainter`), adding zero external pip dependencies and passing `tools/check_frozen.py` (with `'map'` added to the verified pages set).

Respect the Settings text-scale multiplier (90%–130%) across all toolbar and detail panel widgets. On the zoomable `QGraphicsView` canvas (`0.55×` to `3.0×`), `NodeItem.paint()` renders labels in scene coordinates (`14px` scene font, elided to box width with full name tooltip on hover) so text never overflows node pill/diamond boxes, while region halo header banners use `ItemIgnoresTransformations` (`13px` fixed screen font) so regional orientation stays readable at every zoom level.
  - One primary button per screen (`Open in Browser ↗` in cyan fill `#22D3EE` with `#0B1020` text); all other toolbar controls use secondary/pill styling.
  - Right-hand detail panel (`340px` wide) updates on zone selection and clears selection with `Esc`.
- **Protect User Data (`data/`):** Never overwrite `data/ffxi_database.json` or `data/inventory_snapshot.json`. Shipped baseline coordinates live in `vanadiel_nexus/resources/world_map_data.json`; user coordinate overrides are saved via `jsonfile.write_json` to `os.path.join(ctx.data_dir, "world_map_layout.json")`.

## Premises (Agreed & Revised)

1. **Single Canonical Graph Dataset + Drag-to-Arrange (`Revised D8`):** One curated JSON graph (`vanadiel_nexus/resources/world_map_data.json`) keyed to Windower `res/zones.lua` IDs holds all zone metadata, `(x, y)` canvas coordinates, regional clusters, fast-travel flags, and typed edges. Users can adjust `(x, y)` positions visually via an `Arrange Layout` toggle on the canvas rather than editing raw JSON coordinates by hand.
2. **All Navigable + Endgame Content Zones Included (`Revised D6`):** Overworld fields, cities/hubs, dungeons, and major instanced/endgame content zones (Dynamis & Dynamis [D], Omen, Odyssey, Sortie, Limbus, Nyzul/Salvage, Abyssea, Escha/Reisenjima, Walk of Echoes) are first-class nodes on the map connected to their entry hubs, with an `Endgame` filter pill. Multi-layer instance groups (such as `Outer Ra'Kaznar [U1]–[U3]` for Sortie or `Walk of Echoes [P1]–[P2]` for Odyssey) are represented as a single consolidated node carrying all underlying `member_zone_ids` and `aliases` so live `zone_name` tracking matches every sub-instance. Only technical non-zones (`id=0 unknown`, Chocobo Circuit, Mog Houses/Garden, duplicate cutscene sub-IDs) are excluded via an explicit allowlist verified in unit tests.
3. **Zero-Bloat Native Canvas + Single-Source Standalone HTML (`Revised D8`):** The desktop tab renders the graph with native PySide6 `QGraphicsView`, while `Open in Browser ↗` generates a self-contained single-file HTML/SVG viewer (`os.path.join(ctx.data_dir, "exports", "vanadiel_world_map.html")`) from the exact same JSON data and `(x, y)` coordinates—preventing dual-renderer layout drift.
4. **Minimal Canvas, Rich Right-Hand Detail Panel (`D4`):** Map nodes display only the zone name, a subtle shape/border for node kind (`Hub/City` pill, `Field/Dungeon` rounded rect, `Endgame` diamond), and state highlights (`Live Zone` cyan, `Active Route` gold). Detailed metadata (Home Points, Survival Guides, Mount flag, Gate/Key Item requirements, step-by-step route instructions, connected neighbor list, BG-Wiki link) lives in the right-hand detail panel.

### 1. Data Model & Seed Pipeline (`tools/seed_world_map.py` → `vanadiel_nexus/resources/world_map_data.json`)

Because Windower's `res/zones.lua` and `addons/Homepoints/map.lua` provide canonical Zone IDs, English names, `can_mount` flags, and Home Point crystal lists—but do not contain zone-to-zone connectivity (`edges[]`), `has_survival_guide`, or expansion `era` assignments—`tools/seed_world_map.py` combines:
1. **Local Windower Resource Extraction & Unescaping:** Reads `res/zones.lua`, `res/regions.lua`, and `addons/Homepoints/map.lua` (unescaping Lua backslashes `\[`, `\]`, `\#`, `\'` and merging modern post-2015 Home Point additions such as `Reisenjima #1–#9` and `Upper Jeuno #4`) to validate every Zone ID, canonical name, `can_mount` boolean, and Home Point crystal list.
2. **Curated Adjacency & Era Definition Table:** Embeds the ground-truth FFXI zone connection graph (`edges[]` with exit coordinates and gate requirements), Survival Guide flags, and expansion `era` assignments.
3. **Deterministic Non-Overlap Layout Solver (`3600 × 2400` canvas space):** Places regions in recognizable Vana'diel geography (Core/Zilart inner ring around Jeuno; CoP/ToAU/Adoulin mid ring; WotG `[S]`, Abyssea, and Escha outer constellation rings) and runs a deterministic bounding-box collision-relaxation pass (`min_dx = 165px`, `min_dy = 42px` between any two node centers) constrained within regional sectors so `world_map_data.json` is mathematically guaranteed to have zero node or label overlaps at `1.0×` zoom before it is written to disk.

The resulting `vanadiel_nexus/resources/world_map_data.json` (`schema_version = 1`) is committed to the repo and bundled by PyInstaller via `paths.resource_path("world_map_data.json")` so the app works out-of-the-box on any machine.

- **`regions[]`:**
  - `id` (str, e.g. `"ronfaure"`, `"jeuno"`, `"adoulin"`, `"aht_urhgan"`, `"escha"`)
  - `name` (str, e.g. `"Ronfaure & San d'Oria"`)
  - `era` (str — strictly one of the 6 expansion eras: `"core_zilart"`, `"cop"`, `"toau"`, `"wotg"`, `"adoulin"`, `"escha_abyssea"`)
  - `cx`, `cy`, `rx`, `ry` (float — initial center and radii in `3600 × 2400` canvas space; at runtime `RegionHaloItem` dynamically computes its bounding rect from its member `NodeItem` positions + `40px` padding)
- **`zones[]`:**
  - `id` (int — primary canonical Windower `res/zones.lua` ID)
  - `member_zone_ids` (list[int] — all `res/zones.lua` IDs represented by this node; for standard zones `[id]`, for consolidated multi-layer instances like Sortie `[275, 133, 189]` covering `Outer Ra'Kaznar [U1]–[U3]`)
  - `name` (str — full display name, e.g. `"Port Jeuno"`, `"Sortie (Outer Ra'Kaznar [U1–U3])"`)
  - `short_name` (str — canvas node label ≤ 26 chars, e.g. `"Sortie (Ra'Kaznar U1–U3)"`; full `name` is always shown in the detail panel and tooltip)
  - `aliases` (list[str] — exact `res/zones.lua` English names and common abbreviations mapped to this node, e.g. `["Outer Ra'Kaznar [U1]", "Outer Ra'Kaznar [U2]", "Outer Ra'Kaznar [U3]", "Sortie"]`, so live `STATE_UPDATE` `zone_name` lookup and search match every sub-instance)
  - `region_id` (str — foreign key to `regions[].id`)
  - `era` (str — strictly one of: `"core_zilart"`, `"cop"`, `"toau"`, `"wotg"`, `"adoulin"`, `"escha_abyssea"`)
  - `kind` (str — `"hub"` for cities/towns/outpost hubs, `"field"` for outdoor zones, `"dungeon"` for indoor/caves/towers, `"endgame"` for instanced endgame arenas like Sortie, Odyssey, Omen, Dynamis [D], Limbus, Salvage, Nyzul)
  - `x`, `y` (float — node center in `3600 × 2400` canvas space)
  - `can_mount` (bool — from `zones.lua`)
  - `homepoints` (list[str] — from `Homepoints/map.lua` + post-2015 curated supplement, e.g. `["Port Jeuno 1", "Port Jeuno 2"]`)
  - `has_survival_guide` (bool)
  - `wiki_slug` (str | None — optional BG-Wiki URL or page slug override passed into `wiki.build_wiki_urls(zone.name, zone.wiki_slug)["bgwiki"]` for `[S]` zones like `"Southern_San_d'Oria_(S)"` and consolidated endgame nodes like `"Category:Sortie"` or `"Category:Odyssey"`)
  - `notes` (str — concise unlock/entry notes, e.g. `"Enter via Diaphanous Transposer at Outer Ra'Kaznar (G-8)"`)
- **`edges[]`:** (stores physical/portal connections only; fast-travel warps are computed dynamically in `find_route`)
  - `from_id` (int), `to_id` (int)
  - `bidirectional` (bool — `true` for two-way transitions, `false` for one-way drops or one-way teleports)
  - `kind` (str — `"walk"`, `"transport"` for boats/airships/manaclipper, `"warp"` for teleports/confluxes/portals, `"gated"` for key-item/quest doors, `"endgame_entry"` for instance entry points)
  - `exit_pos` (str — optional map coordinate hint, e.g. `"(G-6)"`, `"Airship"`, `"Transposer (G-8)"`)
  - `requirement` (str — optional gate/key-item note, e.g. `"Three Mage Gate / Portal Charm"`, `"Kazham Airship Pass"`, `"Ra'Kaznar Plate"`)

### 2. Core Graph & Route Engine (`vanadiel_nexus/core/world_map.py`)

Pure Python module with zero Qt imports (unit-tested under `tests/core/test_world_map.py`):
- **`load_world_map(resource_path, user_override_path=None) -> WorldMapGraph`:**
  - Loads `vanadiel_nexus/resources/world_map_data.json` via `jsonfile.read_json`.
  - If `user_override_path` (`os.path.join(ctx.data_dir, "world_map_layout.json")`) exists, reads it via `jsonfile.read_json(path, validator=...)`, validates `schema_version == 1`, coerces keys with `int(k)`, and checks `math.isfinite(x)` and `math.isfinite(y)` within `-500..4500` before overlaying `{zone_id: {"x": x, "y": y}}` positions. Malformed or out-of-range overrides fall back cleanly to bundled default coordinates without crashing.
  - Validates that all edge endpoints reference valid `zone.id` entries and builds case-insensitive lookup maps covering `name`, `short_name`, `aliases`, and `member_zone_ids`.
- **`find_route(graph, start_zone_id, target_zone_id, allow_fast_travel=True, include_gated=True, use_hp=True, use_sg=True) -> RouteResult | None`:**
  - Runs Dijkstra's shortest-path algorithm over `WorldMapGraph`.
  - **Edge weights:**
    - Physical `"walk"` edge: `60` cost units if `from_zone.can_mount` is `True`, else `110` cost units.
    - `"transport"` (Boat / Airship): `180` cost units (accounts for schedule wait).
    - `"gated"` edge: `120` cost units when `include_gated=True`, excluded when `include_gated=False`.
    - `"endgame_entry"` / `"warp"` portal edge: `40` cost units.
    - **Dynamic Virtual Fast-Travel Star Hubs (when `allow_fast_travel=True`, keeping traversal $O(V + E)$ instead of $O(V^2)$):**
      - Rather than materializing $O(V^2)$ all-pairs edges in JSON, `find_route()` introduces two strictly separated virtual star-hub nodes in memory during Dijkstra expansion: `VIRTUAL_HP_HUB` (`-1`) and `VIRTUAL_SG_HUB` (`-2`).
      - When `use_hp=True`: stepping from any zone with `len(zone.homepoints) > 0` into `VIRTUAL_HP_HUB` costs `25` units, and exiting `VIRTUAL_HP_HUB` into any destination zone with `len(dest.homepoints) > 0` costs `0` units (collapsing into a single `RouteStep` with `kind="homepoint"`, label `"Home Point Warp -> <Target HP #1>"`).
      - When `use_sg=True`: stepping from any zone with `zone.has_survival_guide is True` into `VIRTUAL_SG_HUB` costs `30` units, and exiting `VIRTUAL_SG_HUB` into any destination zone with `dest.has_survival_guide is True` costs `0` units (collapsing into a single `RouteStep` with `kind="survival_guide"`, label `"Survival Guide Warp -> <Target>"`).
      - Because `VIRTUAL_HP_HUB` and `VIRTUAL_SG_HUB` are separate virtual nodes, a Survival Guide-only zone can never illegally warp directly to a Home Point-only zone without visiting a real zone that possesses both.
      - If `start_zone_id` lacks both a Home Point and a Survival Guide (e.g., an outdoor field), the router also evaluates a one-time initial virtual `"warp_ring"` edge (`cost = 35`) from `start_zone_id` only to `"Port Jeuno"` (Zone ID `246`), from which `VIRTUAL_HP_HUB` / `VIRTUAL_SG_HUB` are immediately reachable.
  - Returns `RouteResult(steps=[RouteStep(from_id, to_id, kind, label, requirement, exit_pos)], total_cost=int)`.
  - **Edge cases handled:** `start_zone_id == target_zone_id` returns a 0-hop route; unknown or disconnected zones return `None` with a clear `"No route found"` message; switching `allow_fast_travel=False` shows the pure walking/boat route.
- **`export_standalone_html(graph, output_path, current_zone_id=None, selected_zone_id=None, active_route=None) -> str`:**
  - Generates a single self-contained `.html` file (`os.path.join(ctx.data_dir, "exports", "vanadiel_world_map.html")`) with inline CSS (`12px` minimum font size), inline SVG rendered at the exact `(x, y)` coordinates from `graph` (including directional arrowheads `▶` on one-way edges and dynamic regional bounding halos), embedded JSON (escaping `</` as `<\/` and `<!--` as `<\!--`) for client-side search, Era/Endgame filter pills, client-side Dijkstra route finder (using the same `VIRTUAL_HP_HUB` and `VIRTUAL_SG_HUB` star-hub weights), right-hand detail drawer, and mouse-wheel/drag pan & zoom.

### 3. Live Zone Signal (`vanadiel_nexus/ui/context.py`) & UI Page (`vanadiel_nexus/ui/pages/world_map.py`)
